 Cardsfolio

Android card management application built with Kotlin and Jetpack Compose.

 Features
- Personal card creation and management
- Favorites system with persistent storage
- Multi-screen navigation using Jetpack Navigation Component
- Material Design 3 UI components
- MVVM architecture with ViewModel

 Tech Stack
- Language: Kotlin
- UI Framework: Jetpack Compose
- Navigation:** Jetpack Navigation Component

 Course Project
Developed as part of CS407: Foundations of Mobile Systems and Applications at University of Wisconsin-Madison.
